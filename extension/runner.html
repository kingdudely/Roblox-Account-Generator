3 Enrol the admin's second factor authenticator app, then the tenant policy waiting
  1. Sign in as the admin and open myaccount.google.com → Security → 2-Step Verification.
  2. Choose Authenticator app, click Can't scan it?, and paste the secret below. The live code finishes Google's setup.
  3. In Admin console → Security → Authentication → 2-Step Verification, set Enforcement On and Methods to Any except verification codes via text, phone call.
    Why exactly this combination Enforcement off leaves a fresh account with no second factor, so Google asks for a phone number. Enforcement on with SMS disallowed makes it offer the authenticator, which the run can enrol with no phone at all. Anything stricter produces the deadlock: “your sign-in settings don't meet your organization's 2-Step Verification policy”.

6 Know the limits what the ceiling actually is reference
  • 50 identities per key, roughly 45 before Google answers 412. That flag is permanent per tenant; deleting users does not clear it.
  • Creation is capped at 10 users per domain per second. The extension paces itself at ~8/s.
  • One Google identity becomes exactly one Roblox account. There is no unlink.
  • Deleting an identity frees the seat; the address stays reserved for about 20 days.
  • Lanes need Firefox containers. Chrome has one cookie jar per profile, so it runs one lane.

Roblox generated keeps the name assigned during SSO signup. Our generator sends a random name from the local word lists with the finalise call and retries if the name is taken. Random under birthday or gender rolls a fresh value per identity instead of reusing the field: birthdays land between 18 and 45, gender picks from unspecified, male, or female. The terms option performs the same acceptance POST as the I Agree button on /not-approved; turn it off if you want to review the updated agreement yourself.

Run defaults

applies to the next batch

Batch count, lanes, timeout, and auto-export stay on the Run tab for quick edits. Concurrency is how many identities are created in the tenant at once; eight is a safe default against Google's directory rate limit.

Lanes

how a lane shows its page

A hidden tab normally gets no animation frames, and Google's sign-in page is built on them — the field fills, the click lands, and the next screen never appears. Background tab injects a small shim into the page's own world that supplies the frame clock and answers visibilityState, so lanes run with no window on screen at all. Own window is the old always-visible fallback, for the case where a page manages to freeze its own visibility getters. The log says which one a lane is using and how many frames it has received.

2-Step Verification

order of operations

Google counts a minted backup code as an enrolled 2SV method. Mint one before the first sign-in and Google stops offering authenticator setup — the account is challenged for a code instead, and ends up with single-use codes as its only second factor. Some tenants then refuse it outright with your sign-in settings don’t meet your organization’s 2-Step Verification policy. Leave the first box off: the run enrols the authenticator, saves otp_secret, and mints the codes once the session lands. Accounts already stuck in the codes-only state get a repair 2sv button on their row.

Egress

one proxy per lane · Firefox only

Lanes cycle through the list, so four lanes with four entries get four exits. SOCKS5 credentials are passed to the browser directly — no prompt, no relay. Each lane logs lane exit ip from inside its own container, so you can see what the other end actually is. Use a sticky proxy. A rotating one hands a different address to every connection, which makes Google challenge the session mid-flow and Roblox see a signup and an upgrade from two countries.

Deletion pacing

Slow on purpose

Delete users on the Setup tab walks the oldest identities first, one at a time, with a jittered pause. A burst of deletes is what Google's abuse filter reacts to, not recycling itself — five a day from a tenant reads as ordinary staff turnover.
